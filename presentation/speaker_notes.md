# Текст выступления по 7 слайдам

**Слайд 1 — Random Forest.** У нас 3000 абонентов. Мы прогнозируем churn по 11 признакам; код абонента исключаем. Лес объединяет предсказания 100 деревьев.

**Слайд 2 — Результаты леса.** Смотрим F1 на train и test и ROC-AUC на test. Большой разрыв F1 означает риск переобучения; судить только по train нельзя.

**Слайд 3 — Анализ леса.** Random Forest подходит как baseline: простой, устойчивый для нелинейных задач. Но в нашем сравнении он сильнее запоминает обучение, поэтому можно ограничить глубину деревьев.

**Слайд 4 — XGBoost.** Градиентный бустинг добавляет деревья последовательно, корректируя ошибки. Параметры: 300 деревьев, learning_rate=0.05, max_depth=4. Данные и разбиение совпадают с лесом.

**Слайд 5 — Результаты XGBoost.** XGBoost лучше по F1 test и ROC-AUC test в сравнении с фотографий, а разрыв train/test меньше. Фактические числа нужно прочитать из запуска по CSV.

**Слайд 6 — Анализ XGBoost.** Модель хорошо обобщает, но требует подбора параметров и проверки на разных выборках. Скорость зависит от системы.

**Слайд 7 — Заключение.** Для текущего эксперимента выбираем метод с более высоким F1 test — XGBoost, если реальные результаты это подтверждают. Для внедрения важно проверить кросс-валидацию, порог и стоимость ошибок.

Для актуализации чисел: \`python scripts/run_experiment.py\`, затем \`python scripts/make_presentation.py\`.
